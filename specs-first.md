# Specs first

Antes de tocar React o el backend:

1. Leer `frontend/specs/README.md`, `api-types.ts` y `param-types.ts`.
2. No inventar endpoints. Solo los de `backend/app/routes.py`.
3. Un array vacío `[]` es un estado vacío de UI, no un error de red.
4. No enviar query params como string vacía. Si no hay fecha, omitir el parámetro.
5. La IA no calcula el veredicto financiero: solo consume lo que devuelve la API.
